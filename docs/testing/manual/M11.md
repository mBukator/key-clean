# M11 manual test - installer and uninstaller

Milestone: M11 (§55, §60 "Windows 10 works", "Windows 11 works", ADR 0019). Run by Max by hand.
Fill in every **Result** line, then send the summary table at the end back.

What M11 adds:

- `KeyClean_0.1.0_x64-setup.exe`: installs for you only (`%LOCALAPPDATA%\KeyClean`), no admin
  prompt, with a Start menu shortcut that lets toasts show as KeyClean;
- "Start KeyClean when I sign in" on the install-location page, ticked for a new install;
- upgrades that keep your startup choice, Task Manager's choice and your settings;
- an uninstaller that closes KeyClean first and leaves nothing behind except, if you choose, your
  settings;
- the new app icon.

**How long:** step 0 about 7 minutes (build) plus 1 minute (automated); steps 1-6 about 15
minutes, including one sign-out (about 2 minutes); steps 7-8 about 10 minutes (a second build);
the Windows 10 part depends on the VM. Steps marked _(optional)_ can be skipped.

**Installed builds are release builds: locks last their real length.** Use the shortest preset or
Custom 10 s. Exits you can use in every lock step: the timer, Ctrl+Alt+K, or a pre-armed
PowerShell command (`Start-Sleep 8; Stop-Process -Name keyclean -Force`). No step needs typing
while the keyboard is locked.

**SmartScreen:** a locally built installer has no "downloaded from the internet" mark, so Windows
shouldn't warn. A copy downloaded from CI (step W1) may show "Windows protected your PC": More
info → Run anyway. The installer is unsigned (ADR 0019).

## Preconditions

- [ ] No KeyClean running: `Get-Process keyclean -ErrorAction SilentlyContinue` prints nothing.
- [ ] No startup entry left from M10's release test:
      `Get-ItemProperty HKCU:\Software\Microsoft\Windows\CurrentVersion\Run -Name KeyClean -ErrorAction SilentlyContinue`
      prints nothing. If it prints a value, open that build and turn Start with Windows off.
- [ ] No Task Manager record left from M10:
      `Get-ItemProperty HKCU:\Software\Microsoft\Windows\CurrentVersion\Explorer\StartupApproved\Run -Name KeyClean -ErrorAction SilentlyContinue`
      prints nothing. If it prints one, a "Disable" from M10 would apply to the new entry too;
      remove it with
      `Remove-ItemProperty HKCU:\Software\Microsoft\Windows\CurrentVersion\Explorer\StartupApproved\Run -Name KeyClean`.
- [ ] Settings → System → Notifications: notifications on.

## 0. Build and the automated installer checks (S52-S53)

In PowerShell, from `D:\Projects\personal\key-clean`:

```powershell
bun tauri build
```

```powershell
cargo run -p keyclean-e2e -- --installer
```

**Expected:** the build ends with `KeyClean_0.1.0_x64-setup.exe (1.78 MiB)` or close. The checks
take under a minute, lock nothing, and report S52 and S53 PASS: a silent install into
`%TEMP%\KeyClean e2e install` (a path with a space), the exact startup value, the shortcut's
AppUserModelID, the publisher, no desktop shortcut, no machine-wide entry; then a silent uninstall
with KeyClean running that closes it and leaves nothing (your settings stay).

## 2. What the installer wrote (read-only)

```powershell
(Get-ItemProperty HKCU:\Software\Microsoft\Windows\CurrentVersion\Run -Name KeyClean).KeyClean
(New-Object -ComObject Shell.Application).Namespace([Environment]::GetFolderPath('Programs')).ParseName('KeyClean.lnk').ExtendedProperty('System.AppUserModel.ID')
Get-ItemProperty HKCU:\Software\Microsoft\Windows\CurrentVersion\Uninstall\KeyClean | Select-Object DisplayName, DisplayVersion, Publisher, InstallLocation
Test-Path HKLM:\Software\Microsoft\Windows\CurrentVersion\Uninstall\KeyClean
Test-Path "$([Environment]::GetFolderPath('Desktop'))\KeyClean.lnk"
```

**Expected:** `"C:\Users\<you>\AppData\Local\KeyClean\keyclean.exe" --autostart`;
`io.github.mbukator.keyclean`; KeyClean, 0.1.0, mBukator, the quoted folder; `False`; `False`.

## 6. Reinstall while a lock runs (needs your second monitor)

1. Move the pointer to the second monitor. In the dashboard choose 1 minute, keyboard only, and
   prepare (don't press Enter yet) in PowerShell on the main display:
   `Start-Sleep 5; Start-Process .\target\release\bundle\nsis\KeyClean_0.1.0_x64-setup.exe`
2. Press Enter, then click **Lock** on the second monitor within 5 s. The overlay covers the second
   monitor; the installer opens on the main display.
3. With the mouse: Add/Reinstall → Next → the checkbox is ticked → Install.

**Expected:** before copying files the installer asks "KeyClean is running and will be closed. If
a lock is in progress, it ends and your keyboard and mouse work again." OK: the overlay disappears
and the keyboard works at once (type in Notepad); the install finishes. Cancel instead: "KeyClean
is still running..." and the install stops, with KeyClean still running. Ctrl+Alt+K or the 1 min
timer end the lock if anything goes wrong.

**Result:**

## 7. An upgrade keeps your choices

1. Task Manager → Startup apps → KeyClean → **Disable**.
2. Build version 0.1.1 (about 6 minutes):

    ```powershell
    '{"version":"0.1.1"}' | Set-Content $env:TEMP\keyclean-v.json; bun tauri build --config $env:TEMP\keyclean-v.json
    ```

3. With KeyClean running in the tray, run `KeyClean_0.1.1_x64-setup.exe`. There is no "already
   installed" page: Welcome → install location (the checkbox ticked) → Install. The close
   question comes; OK. Finish.

**Expected:** no uninstaller runs for the old version. Afterwards Task Manager still shows
KeyClean **Disabled**; Settings → General shows "Turned off in Task Manager → Startup apps"; your
settings are kept (the start shortcut is still Alt+Shift+1); Apps & features shows 0.1.1.

**Result:**

## 8. A startup entry you turned off stays off _(optional)_

1. Task Manager → Startup apps → KeyClean → **Enable**. In Settings → General turn Start with

2. Run `KeyClean_0.1.1_x64-setup.exe` again: Add/Reinstall.

**Expected:** the install-location page shows the checkbox **unticked**; after installing,
`Get-ItemProperty HKCU:\Software\Microsoft\Windows\CurrentVersion\Run -Name KeyClean -ErrorAction SilentlyContinue`
prints nothing. Tick it on another reinstall if you want the entry back for step 9.

**Result:**

## 9. Uninstall leaves nothing behind

1. Start KeyClean if it isn't running. Settings → Apps → Installed apps → KeyClean → Uninstall.
2. On the confirm page, "Also delete my KeyClean settings" is unticked; leave it. Click
   Uninstall, then OK the close question that follows.
3. Run the read-only check:

```powershell
[pscustomobject]@{
  RunValue = (Get-ItemProperty HKCU:\Software\Microsoft\Windows\CurrentVersion\Run -Name KeyClean -ErrorAction SilentlyContinue).KeyClean
  TaskManagerRecord = [bool](Get-ItemProperty HKCU:\Software\Microsoft\Windows\CurrentVersion\Explorer\StartupApproved\Run -Name KeyClean -ErrorAction SilentlyContinue)
  InstallFolder = Test-Path "$env:LOCALAPPDATA\KeyClean"
  StartMenuShortcut = Test-Path "$([Environment]::GetFolderPath('Programs'))\KeyClean.lnk"
  AppsEntry = Test-Path HKCU:\Software\Microsoft\Windows\CurrentVersion\Uninstall\KeyClean
  InstallRecord = Test-Path HKCU:\Software\mBukator
  WebView2Data = Test-Path "$env:LOCALAPPDATA\io.github.mbukator.keyclean"
  Settings = Test-Path "$env:APPDATA\io.github.mbukator.keyclean"
  ScancodeMap = [bool](Get-ItemProperty 'HKLM:\SYSTEM\CurrentControlSet\Control\Keyboard Layout' -Name 'Scancode Map' -ErrorAction SilentlyContinue)
  Processes = @(Get-Process keyclean -ErrorAction SilentlyContinue).Count
} | Format-List
```

**Expected:** KeyClean closes before anything is removed; no tray icon is left. Every line is
empty, `False` or `0`, except `Settings : True`. (No lock state exists anywhere to remove: hooks
end with the process, and KeyClean never writes a Scancode Map or disables a device.)

**Result:**
