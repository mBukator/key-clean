# M6 manual test - full-screen overlay

Milestone: M6 (§13-§18, §45, ADR 0014). Run by Max by hand. Fill in every **Result** line, then send
the summary table at the end back.

What M6 adds: every lock first shows a dark full-screen overlay on the monitor under the mouse
pointer, and locks only once the overlay is on screen. The overlay shows the countdown, what is
locked and Ctrl + Alt + K. If the overlay goes away during a lock (closed, hidden, minimized, left on
another desktop), the lock ends.

**How long:** Part A about 9 minutes, Part B about 10 minutes. Part C is optional.

**Exits you can use in every lock step:** wait for the timer (debug builds stop after 15 s), press
Ctrl+Alt+K, or let a pre-armed PowerShell command kill KeyClean. With the mouse locked, the overlay
has no **Unlock now** button.

**Build and start.** This milestone uses a debug exe with the UI built in, not `bun tauri dev`, so
killing KeyClean doesn't end a dev server. In PowerShell, from `D:\Projects\personal\key-clean`:

```powershell
bun run build; cargo build -p keyclean --features tauri/custom-protocol
.\target\debug\keyclean.exe
```

KeyClean's log lines (`[keyclean] ...`, session events only) appear in that PowerShell window. With
`bun tauri dev` the first lock may fail with "The lock screen didn't appear in time" while the dev
server compiles the overlay page; a second try then works.

## Preconditions

- [ ] A PowerShell window open (for step 7).
- [ ] Notepad open (for step 5).
- [ ] For step 6c only: a second virtual desktop (Task View, then **New desktop**), then back on
      the first one.

## Part A - automated run (about 9 minutes)

1. Close any running KeyClean. Rebuild, then run the harness and keep your hands off the keyboard
   and mouse:

    ```powershell
    cargo build -p keyclean-win --example lock_smoke
    bun run build; cargo build -p keyclean --features tauri/custom-protocol
    cargo run -p keyclean-e2e
    ```

    Expected: every check passes, including S14 (Ctrl+Alt+K with the overlay focused) and the new
    overlay checks S34-S40. If S34 fails on the rectangle, copy both rectangles it prints.

    **Result:**

2. **Overlay latency.** Run:

    ```powershell
    cargo run -p keyclean-e2e -- --overlay-latency --only S41
    ```

    Copy the cold, p50, p95 and max numbers it prints. Expected: every lock under 2000 ms.

    **Result:**

## Part B - by hand (essential)

Start the app: `.\target\debug\keyclean.exe`. Every lock lasts 15 s.

3. **Keyboard lock, ended by the timer.** Tick only **Keyboard**, click **Start lock**. Expected:
    - The overlay appears on the monitor with the mouse pointer and covers it fully, taskbar
      included, with no white flash first.
    - Top left: "KeyClean" and "Input locked · Keyboard". Top right: **DEV CAP** and **Unlock now**.
    - The countdown starts at 00:15 and counts down, with a segmented bar.
    - Bottom right: "Emergency unlock:", the Ctrl, Alt and K key caps and "Press the shortcut to
      unlock immediately."
    - From 00:05: "Unlocking in 5 seconds" (then 4, 3, 2, 1 second) in orange.
    - At the end the overlay disappears at once and the main window comes to the front with
      "Cleaning complete".

    **Result:**

4. **Unlock now and Ctrl+Alt+K.** Start a keyboard lock and click **Unlock now** on the overlay.
   Then start another and press Ctrl+Alt+K. Expected: each time the overlay disappears at once and
   the window says the lock was cancelled, then that you pressed the emergency shortcut.

    **Result:**

5. **Mouse only, and both.** Tick only **Mouse and touchpad**, click **Start lock**. Expected: the
   header says "Mouse and touchpad", there is no Unlock now button, and a line says touchpad gestures
   still work. The pointer doesn't move. Type a few letters: nothing appears in Notepad or anywhere
   else. Press Ctrl+Alt+K to end it. The overlay with the mouse locked has no design yet: say whether
   it looks right.

    Then tick both and lock. Expected: "Keyboard, mouse and touchpad", no Unlock now. Let the timer
    end it.

    **Result:**

6. **Touchpad gestures.** Tick both, then for each gesture start a new lock and do it once on the
   laptop touchpad. Let the timer end any lock that keeps going. Record for each: did the overlay
   stay, and did the lock end early (the window then says the lock ended because "its lock screen
   was closed or hidden")? If it ended early, copy the `overlay lost (...)` line from the PowerShell
   window: it names the cause (Minimized, OtherDesktop, Silent, ...).
    - a. Three-finger swipe up (Task View). Expected: Task View opens over the overlay and the lock
      goes on; after the timer the overlay disappears.
    - b. Three-finger swipe down (Show desktop). Expected: either nothing happens, or the overlay is
      minimized and the lock ends within about 1 s.
    - c. _(Needs the second desktop.)_ Four-finger swipe left or right. Expected: the lock ends
      within about 1 s. Swipe back afterwards.

    **Result:**

7. **Kill mid-lock.** In PowerShell, run `Start-Sleep 8; Stop-Process -Name keyclean -Force`, then
   at once tick both in KeyClean and click **Start lock**. Expected: after about 8 s the overlay and
   KeyClean are gone and the keyboard and mouse work. (This also ends any `bun tauri dev`.) Start
   `.\target\debug\keyclean.exe` again for the next step.

    **Result:**

8. **Focus.** Tick only **Keyboard**, start a lock, click an empty spot on the overlay, then press
   the Windows key. Expected: the Start menu doesn't open. Then press Ctrl+Alt+K once: the lock ends
   at the first try.

    **Result:**

## Part C - optional

9. _(Optional, needs a second monitor.)_ **Second monitor and scaling.** Drag the KeyClean window
   to the second monitor, tick only **Keyboard** and click **Start lock** there. The overlay goes to
   the monitor the pointer is on when you click. Expected: it covers that monitor exactly and leaves
   the other one uncovered. If the two monitors use different scaling (Settings, Display, Scale),
   repeat on each and check the overlay still fits exactly.

    **Result:**

10. _(Optional)_ **Release build latency.** Close the debug KeyClean first (only one KeyClean can
    run, and a second one hands over to it). Build and start the release exe with its log saved,
    lock twice (30 s each, end with Ctrl+Alt+K), close KeyClean, then read the numbers:

    ```powershell
    bun tauri build
    Start-Process .\target\release\keyclean.exe -RedirectStandardError overlay-release.log
    Select-String "overlay:" overlay-release.log
    ```

    **Result:**
