# M7 manual test - MVP dashboard

Milestone: M7 (§9-§12, §32, §45, §46, ADR 0015). Run by Max by hand. Fill in every **Result** line,
then send the summary table at the end back.

What M7 adds:

- the Clean, Devices and Settings tabs;
- Custom durations from 10 s up to the max-lock setting;
- Settings → Safety → Maximum lock duration (1-60 min);
- the last duration and targets remembered;
- the display kept on during a lock;
- one shared error block with "View technical details".

**How long:** step 0 about 7 minutes (automated), Part A about 15 minutes. Part B is optional
(release build, about 8 minutes).

**Exits you can use in every lock step:** wait for the timer (debug builds stop after 15 s), press
Ctrl+Alt+K, or let a pre-armed PowerShell command kill KeyClean. Typing values (Custom, Settings)
only ever happens while nothing is locked.

**Build and start.** In PowerShell, from `D:\Projects\personal\key-clean`:

```powershell
bun run build; cargo build -p keyclean --features tauri/custom-protocol
.\target\debug\keyclean.exe
```

The settings file is `%APPDATA%\io.github.mbukator.keyclean\settings.json`.

## Preconditions

- [ ] No KeyClean running. Delete the settings file so the test starts from the defaults:
      `Remove-Item "$env:APPDATA\io.github.mbukator.keyclean\settings.json" -ErrorAction SilentlyContinue`
- [ ] For step 7: a PowerShell window opened with **Run as administrator**.
- [ ] For step 8: Windows set to sleep when you press the power button or close the lid (the
      default on most laptops).

## Step 0 - harness regression (about 7 minutes)

M7 changed the overlay path the harness guards: the display request lives with the overlay record,
`lock_input` checks a range, and the overlay page imports shared helpers. No scenario is new.

0. Close any running KeyClean, then run the harness and keep your hands off the keyboard and mouse:

    ```powershell
    cargo build -p keyclean-win --example lock_smoke
    bun run build; cargo build -p keyclean --features tauri/custom-protocol
    cargo run -p keyclean-e2e
    ```

    Expected: every check passes, as in M6 (S1-S40).

## Part A - debug build (about 15 minutes)

1. **Ready screen.** Start KeyClean. Compare it with `docs/design/clean-ready.png`.

    Expected:
    - The tabs are Clean, Devices and Settings, with no Test tab.
    - The panel shows `READY · LOCK FOR`, `02:00`, Keyboard ON, Mouse OFF and Touchpad OFF.
    - The presets read `30 s`, `1 min`, `2 min` (selected), `5 min` and `Custom`.
    - The Keyboard tile reads On and the Mouse tile Off. The Touchpad tile is marked Limited and
      reads "Follows mouse · Off". Clicking it does nothing.
    - A **DEV CAP** badge sits at the top right. The window is about 760x600.

    Switch Windows to dark mode (Settings → Personalization → Colors). Expected: KeyClean turns dark
    at once and matches the dark half of the design. Switch back if you like.

    **Result:**

2. **Narrow window and long text.** Drag the window's right edge to its minimum width.

    Expected: the controls stack into one column, with the Lock tile below the tiles. No text is cut
    off or overlaps, and the window scrolls if needed.

    **Result:**

3. **Keyboard use at idle.**
    - Press Tab: the focus ring is visible on every control.
    - On the tabs, Left and Right switch between Clean, Devices and Settings.
    - In the presets, the arrow keys move the selection, and Custom is reachable.
    - Space toggles the Keyboard and Mouse tiles. Turn both off: the Lock tile reads "Choose the
      keyboard, the mouse, or both before locking." and is disabled. Turn Keyboard back on.

    **Result:**

4. **Custom duration, ended by the timer.**
    - Click **Custom**. Expected: the hint "Choose a length from 10 seconds to 30 minutes."
    - Enter 0 minutes and 5 seconds. Expected: "That length is outside the range above." in the
      error colour, with a `!`, and Lock disabled. Enter 75 seconds: "Enter whole minutes, and
      seconds from 0 to 59."
    - Enter 0 minutes and 12 seconds, then click **Lock**. Expected: the overlay shows `00:12` and
      the lock ends by itself after about 12 s.
    - The main window comes back with "Cleaning complete. Everything is unlocked again."

    **Result:**

5. **Remembered choices.**
    - Close KeyClean (X) and start it again. Expected: Custom is selected with 0:12, and Keyboard is
      on.
    - Now pick **1 min**, turn **Mouse** on and click Lock. Expected: the overlay has no Unlock now
      button. Press **Ctrl+Alt+K**: the lock ends with "Last lock ended: you pressed the emergency
      shortcut."
    - Close and start KeyClean again. Expected: 1 min is selected, and Keyboard and Mouse are both
      on.

    **Result:**

6. **Maximum lock duration.**
    - Open **Settings**. Type `0`, then `61`, then `abc`. Expected: each time "Enter a whole number
      of minutes from 1 to 60.", and Save is disabled.
    - Type `1` and click **Save**. Expected: "Saved. The next lock uses the new limit."
    - Back on **Clean**, expected:
        - `2 min` and `5 min` are disabled, with a hint that names 1 minute and Settings.
        - The 1 min choice from step 5 is still selected.
        - Custom's hint now says up to 1 minute, and 1 min 30 s shows the out-of-range message.
    - In Settings set `30` and Save. Restart KeyClean. Expected: Settings shows 30.

    **Result:**

7. **The display stays on, and the request goes away.** Start KeyClean (Keyboard only, 1 min).
    - In the **admin** PowerShell, type this and press Enter, then click **Lock** within 6 seconds:

        ```powershell
        Start-Sleep 6; powercfg /requests
        ```

        Expected (printed during the lock; read it once the lock ends): under **DISPLAY:** and
        **SYSTEM:**, an entry for `keyclean.exe` with "KeyClean keeps the screen on during a
        cleaning session."

    - Once the lock has ended, run `powercfg /requests` again. Expected: no `keyclean.exe` entry.
    - Kill test. Pre-arm this, then click **Lock**:

        ```powershell
        Start-Sleep 6; Stop-Process -Name keyclean -Force; Start-Sleep 1; powercfg /requests
        ```

        Expected: KeyClean is gone, input works, and there is no `keyclean.exe` entry.

    **Result:**

8. **Sleep still ends a lock.** Start KeyClean (Keyboard only) and click **Lock**. Within the 15 s,
   press the power button or close the lid.

    Expected:
    - The computer goes to sleep. The display request doesn't hold it awake.
    - After waking and signing in, KeyClean is idle and says the lock ended because the computer went
      to sleep or was locked (M3 saw "locked").

    **Result:**

9. **Shared error block.** Close KeyClean. Start it with the overlay fault switch, which only works
   in debug builds:

    ```powershell
    $env:KEYCLEAN_E2E_OVERLAY = 'no-ack'; .\target\debug\keyclean.exe
    ```

    - Click **Lock**. Expected: after about 2 s, "The lock screen didn't appear in time, so nothing
      was locked. Try again." with a `!`, and nothing was locked.
    - **View technical details** opens and shows the timings, and the keyboard can reach it.
    - Close KeyClean and run `Remove-Item Env:KEYCLEAN_E2E_OVERLAY`.

    **Result:**

10. **Devices tab.** Start KeyClean and open **Devices**.

    Expected:
    - The groups are Keyboards, Mice and Touchpads, each device with a Supported or Limited badge.
      The touchpad note explains Limited.
    - Unplug the HyperX keyboard: it leaves the list within a second or two. Plug it back in: it
      returns.

    **Result:**

11. _(Optional)_ **Corrupt settings file.** Close KeyClean, then run:

    ```powershell
    Set-Content "$env:APPDATA\io.github.mbukator.keyclean\settings.json" 'not json'
    ```

    Start KeyClean. Expected: 2 min, Keyboard only, and Settings shows 30. Click Lock once (any
    exit). Expected: the file is valid JSON again.

    **Result:**

## Part B - release build, real durations (optional, about 8 minutes)

Build once with `bun tauri build`, then run `.\target\release\keyclean.exe`. There is no DEV CAP, and
no console. Start from the defaults, which means deleting the settings file first.

12. **Custom in release.** Custom 0 min 20 s, then Lock. Expected: the overlay shows `00:20` and the
    lock ends after about 20 s with "Cleaning complete."

    **Result:**

13. **A lock as long as the max lock.** In Settings set **1** minute and Save. On Clean, pick
    **1 min** and click Lock. Let it run out.

    Expected: "Cleaning complete. Everything is unlocked again." and **not** "the safety time limit
    was reached". (The lock and its hard deadline end at the same moment; ADR 0015.) Set the max
    lock back to 30.

    **Result:**

14. _(Optional)_ **Display on during a long lock.** In Windows set "Turn off my screen after" to
    **1 minute**. Lock for **2 min**. Expected: the screen stays on until the lock ends. Restore your
    setting.

    **Result:**
