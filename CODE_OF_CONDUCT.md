# Code of Conduct

KeyClean adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

All contributors and maintainers are expected to follow it in every project space, including issues, pull requests, and discussions.

## Reporting

To report unacceptable behavior, contact the maintainer through GitHub ([@mBukator](https://github.com/mBukator)). Reports are handled privately.
